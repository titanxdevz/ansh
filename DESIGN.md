# DESIGN SYSTEM & DIRECTION: ANSH PORTFOLIO

## 1. Identity & Narrative
- **Owner**: Ansh — Discord bot developer, full-stack systems engineer, hosting infrastructure operator (VexaNode).
- **Core Narrative**: High-craft engineering without AI slop or marketing fluff. Ansh builds bots that stay online across 10,000+ guilds, deploys Pterodactyl server nodes and Cloudflare Tunnels that don't flap, and hardens web applications against real CVEs (SSRF, ReDoS, IDOR, SVG XSS).
- **Location**: Gorakhpur, Uttar Pradesh, India. Works in Hinglish (Hindi + English) with clients across India and globally.

## 2. Aesthetic & Visual Rules (Anti-Slop Standard)
- **Palette**:
  - Base: Deep industrial obsidian and matte graphite (`#0b0d13`, `#121620`, `#181e2b`).
  - Text: Warm crisp parchment (`#f1ede6`) and muted steel (`#9ba3b4`).
  - Primary Accent: Amber/copper furnace glow (`#f59e0b` / `#fbbf24`), representing server power LEDs and heat sinks.
  - Telemetry Accent: Emerald heartbeat (`#10b981`), representing 99.98% uptime and live node health.
  - Border: Crisp 1px translucent lines (`rgba(241, 237, 230, 0.09)`), never bulbous gradients.
- **Typography**:
  - Headings: `Outfit Variable` — Geometric, confident, structured.
  - Telemetry / Code / Shell: `JetBrains Mono Variable` — Precise monospaced data, shell prompts, port numbers, latency metrics.
  - Body: `DM Sans Variable` — Readable, humane, legible at all sizes.
- **Tactile Details**:
  - Keycap bevels and physical switch styling.
  - High-contrast accessibility compliant with WCAG AA/AAA.
  - Zero arbitrary floating neon orbs or generic AI purple-cyan gradients.
  - Interactive tactile controls inspired by the best engineering components on `21st.dev`.

## 3. 21st.dev Component Lineup & Integration
1. **Interactive Portfolio Terminal**: Full interactive shell emulator with `$ help`, `$ projects`, `$ stats`, `$ uptime`, `$ contact`.
2. **Discord Bot Components V2 Simulator**: Real-time simulated Discord interface showcasing audio bot playback, Kazagumo shard metrics, and Discord action buttons.
3. **Live Infrastructure Telemetry**: VexaNode server heartbeat, Wings daemon latency, Cloudflare tunnel status, and WAL checkpoint meters.
4. **Interactive Bento Project Showcase**: Multi-tab filtered engineering cards with architecture highlights and direct code/spec metrics.
5. **Tactile Floating Dock**: Bottom navigation bar with spring hover magnification and keyboard hotkeys.
6. **Security Audit Remediation Grid**: Transparent audit ledger of real CVE remediations (SSRF, ReDoS, IDOR, SVG XSS).
7. **Transparent Services & Engagement Ledger**: Clear deliverables, pricing, and communication channels.
